# Fonts

The profile graphics convert text to vector paths with these fonts, so every visitor sees the same typography. All three are licensed under the SIL Open Font License 1.1.

| File | Font | Source |
|---|---|---|
| `jost-latin.woff2` | Jost | https://github.com/indestructible-type/Jost |
| `dm-sans-latin.woff2` | DM Sans | https://github.com/googlefonts/dm-fonts |
| `plex-mono-latin.woff2` | IBM Plex Mono | https://github.com/IBM/plex |
