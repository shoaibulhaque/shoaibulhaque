<br>

**Software Engineer** with a **Computer Systems Engineering** background, focused on backend systems, cloud infrastructure, distributed workloads, and production AI. My work spans application architecture, data and asynchronous processing, integrations, deployment, observability, and reliability.

I’m especially interested in the boundary between application code and the systems that keep software dependable in production: clear architecture, deliberate failure handling, operational visibility, and scaling based on real requirements.

<br>

## `01 / engineering scope`

**Backend & Distributed Systems**  
API and domain architecture, multi-tenancy, authentication and authorization, integrations, payments, real-time communication, event-driven flows, queues, and asynchronous workloads.

**Cloud & Platform**  
Networking, DNS/TLS, Linux, containers, reverse proxies, cloud infrastructure, CI/CD, deployment architecture, observability, and production reliability.

**AI Systems**  
LLM applications, retrieval and RAG, agentic workflows, tool integration, orchestration, evaluation, and automation connected to production software.

**Product Engineering**  
End-to-end delivery across backend and frontend boundaries, component architecture, responsive interfaces, and design-system implementation.
